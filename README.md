# VisionQC

An industrial AI-powered visual defect detection and quality inspection platform.

## Project goals

- Detect and analyse visual defects in manufactured products.
- Build reproducible computer vision and machine learning pipelines.
- Apply data quality checks and scalable data processing.
- Expose predictions through an API.
- Provide a dashboard for inspection history and model performance.

## Planned technology stack

- Python, PyTorch, OpenCV
- FastAPI
- PostgreSQL
- React
- Git and Docker
